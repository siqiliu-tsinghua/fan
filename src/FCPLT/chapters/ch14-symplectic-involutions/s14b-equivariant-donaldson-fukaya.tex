\paragraph{\trEquivariant{}\trDonaldson--\trFukayaCategory。}\label{sub:equivariant-donaldson-fukaya}
值得看看上面做出的这些定义如何纳入 \cref{sub:autoequivalences}与\cref{sub:automorphisms}
中更抽象的讨论。
设我们给定一个带有\trCoherent{} $\ZZ/2$-作用的\trCategory{} $A$。它由一个%
\trAutoequivalence{} $E\colon A\to A$ 和一个\trFunctor\trIsomorphism{} $T\colon E^2\to
\mathrm{Id}_A$ 组成，满足单一的\trCoherent{}条件 $R_E(T)=L_E(T)$；或者更具体地说，即
\begin{equation}\label{eq:coherence-condition}
T_{E(X)}=E(T_X)\in\Hom_A\bigl(E^3(X),E(X)\bigr)\qquad\text{对一切 }X.
\end{equation}
于是可以如下定义一个新\trCategory{} $A^{\mathrm{strict}}$。\trObject{}形如
$(X_+,F_+,X_-,F_-)$，其中 $X_\pm$ 是 $A$ 的\trObject，而 $F_\pm\colon X_\pm\to E(X_\mp)$
是\trIsomorphism，使得 $E(F_-)\circ F_+\colon X_+\to E^2(X_+)$ 等于 $T^{-1}_{X_+}$
（由于 \eqref{eq:coherence-condition}，从 $X_-$ 出发的相应性质随后会自动成立）。在
$A^{\mathrm{strict}}$ 中从 $(X_{0,\pm},F_{0,\pm})$ 到 $(X_{1,\pm},F_{1,\pm})$ 的%
\trMorphism，无非是 $A$ 中从 $X_{0,+}$ 到 $X_{1,+}$ 的\trMorphism，这立即可见
$A^{\mathrm{strict}}$ \trEquivalence{}于 $A$。然而，我们现在有了一个严格的 $\ZZ/2$-作用，
它由\trFunctor{} $E^{\mathrm{strict}}$ 给出：后者交换\trObject{}的 $+$、$-$ 两部分，并把
\begin{equation*}
\Phi\in\Hom_A(X_{0,+},X_{1,+})\longmapsto
F^{-1}_{1,-}\circ E(\Phi)\circ F_{0,-}\in\Hom_A(X_{0,-},X_{1,-}).
\end{equation*}
特别地，$A^{\mathrm{strict}}$ 的一个在 $E^{\mathrm{strict}}$ 之下不变的\trObject，由
$A$ 的单个\trObject{} $X$ 连同一个满足 $E(F)\circ F=T^{-1}_X$ 的\trIsomorphism{}
$F\colon X\to E(X)$ 给出。若 $(X_0,F_0)$ 与 $(X_1,F_1)$ 是两个这样的\trObject，则%
\trMorphism{}群 $\Hom_{A^{\mathrm{strict}}}(X_0,X_1)=\Hom_A(X_0,X_1)$ 带有一个自然的%
\trInvolution，即 $E^{\mathrm{strict}}(\Phi)=F^{-1}_1\circ E(\Phi)\circ F_0$。
让我们转到几何情形：$M$ 是一个带角的\trExactSymplectic\trManifold，配有二次复%
\trVolume{}形式 $\eta_M^2$。设我们有 $M$ 的一个\trInvolution{} $\iota_M$，它保持全部
给定结构（$\varpi_M$、$I_M$ 以及 1-形式 $\theta_M$；今后凡谈及\trExactSymplectic%
\trManifold{}的\trInvolution，这都将是一条常设假定）。给它添上平凡\trGrading（等于零）
与\trLineBundle{} $\beta=\xi_M$，便把它做成一个\trBrane\trAutomorphism{} $\iota'_M$。
依一般的理由，这定义了\trDonaldson--\trFukayaCategory{}的一个唯一的\trAutoequivalence，
它就是我们的 $E$（我们此前对在边界附近等于恒同的\trAutomorphism{}考虑过这个构造；
不过，除\trExact{}性之外，人们所需要的只是较弱的条件：该\trAutomorphism{}在边界附近
保持 $I_M$——这在这里显然满足）。可以利用来自 \cref{thm:grading-relative-orientation}
的\trIsomorphism{} $\xi_M|L\cong\lambda^{\mathrm{top}}(TL)$，把 $E$ 在\trObject{}上的
作用写作
\begin{equation}\label{eq:involution-on-objects}
(L,\alpha^{\#},P^{\#})\longmapsto
\bigl(\iota_M(L),\,\alpha^{\#}\circ\iota_M,\,
\iota_M^*(P^{\#}\otimes\lambda^{\mathrm{top}}(TL))\bigr).
\end{equation}
由于 $\iota'_M\circ\iota'_M=(\mathrm{Id}_M,\,0,\,\xi_M\otimes\iota_M^*\xi_M)$ 是平凡的，
$E^2=E\circ E$ 与恒同\trFunctor{} \trIsomorphic。更精确地说，$\xi_M\otimes\iota_M^*\xi_M$
的一个\trTrivialization{}给出一个\trIsomorphism{} $T\colon E^2\to\mathrm{Id}$。有一种显然的这种%
\trTrivialization{}，它经由\trIsomorphism{} $\lambda^{\mathrm{top}}(D\iota_M)\colon\xi_M\to\iota_M^*\xi_M$
定义，但我们想把它乘以 $-1$ 再取相应的 $T$。这条唯一非平凡的\trCoherent{}条件
\eqref{eq:coherence-condition} 归结为下述简单事实：我们的\trTrivialization{}自身是 $\ZZ/2$-不变的
（所用的作用由按 $\iota_M$ \trPullback{}并交换两个因子构成）。
现在显然，我们对预\trEquivariant{}\trBrane{}的定义，无非是上面进行的那个抽象代数构造的一个
实例。特别是，存在一个 $\KK$-\trLinear{}的\trGraded\trCategory{} $H\scr{F}(M)^{\mathrm{strict}}$，
其\trObject{}是预\trEquivariant{}\trBrane，\trMorphism{}空间为 $HF^*(L^{\#}_{0,+},L^{\#}_{1,+})$。
它与 $H\scr{F}(M)$ \trEquivalence，而它唯一的优点是带有严格的、而非\trCoherent{}的
$\ZZ/2$-作用。在\trObject{}上，这个作用由前面描述过的\trInvolution{} $\epsilon$ 给出；
在\trMorphism{}上，则令
\begin{equation}\label{eq:involution-on-morphisms}
\begin{aligned}
\epsilon\colon HF^*(L^{\#}_{0,+},L^{\#}_{1,+})
&\xrightarrow{\ \cong\ }
HF^*\bigl(L^{\#}_{0,+}\otimes\lambda^{\mathrm{top}}(TL_{0,+}),
L^{\#}_{1,+}\otimes\lambda^{\mathrm{top}}(TL_{1,+})\bigr)\\
&\xrightarrow{\ \cong\ }
HF^*\Bigl(\iota_M\bigl(L^{\#}_{0,+}\otimes\lambda^{\mathrm{top}}(TL_{0,+})\bigr),
\iota_M\bigl(L^{\#}_{1,+}\otimes\lambda^{\mathrm{top}}(TL_{1,+})\bigr)\Bigr)\\
&\xrightarrow{\ \cong\ } HF^*(L^{\#}_{0,-},L^{\#}_{1,-})
\end{aligned}
\end{equation}
其中第一个\trIsomorphism{}用到如下事实：诸 $\lambda^{\mathrm{top}}(TL_{k,+})$ \trCanonical{}地%
\trIsomorphic{}于一个公共\trLineBundle{} $\xi_M$ 的限制，比较 \eqref{eq:involution-on-objects}；
第二个是\trGrading{}辛\trAutomorphism{}之下的\trFunctoriality；第三个来自与 $f_{0,-}$、$f_{1,-}$ 的\trComposition{}。
关于 $H\scr{F}(M)^{\mathrm{strict}}$ 上的 $\ZZ/2$-作用，还能再说上几句，基本上就是
\cref{sub:floer-cohomology-for-branes} 中所述诸性质的\trEquivariant{}版本。我们略去证明——它们
是直截了当的。
\begin{itemize}
\item \emph{改变正负号}。设 $\beta\to M$ 是带有非平凡 $\ZZ/2$-作用的平凡\trLineBundle。
显然，对一切预\trEquivariant{}\trBrane{} $L^{\#}_{k,+}$ 都有 $HF^*(L^{\#}_{0,+},L^{\#}_{1,+}\otimes
\beta|L_{1,+})=HF^*(L^{\#}_{0,+},L^{\#}_{1,+})$，但这些\trIsomorphism{}与
\eqref{eq:involution-on-morphisms} 反交换。特别是，若 $L^{\#}_0$ 与 $L^{\#}_1$ 是真正
的\trEquivariant{}\trBrane，则把其中之一与 $\beta$ 作张量，会反转 $HF^*(L^{\#}_0,L^{\#}_1)$ 上
$\ZZ/2$-作用的正负号，从而（若基域满足 $\mathrm{char}(\KK)\neq 2$）交换其不变与反不变
部分。
\item \emph{PSS~\trIsomorphism}。若 $L^{\#}$ 是\trEquivariant{}\trBrane，则 PSS~\trIsomorphism{}
$HF^*(L^{\#},L^{\#})\cong H^*(L;\KK)$ 与两侧的 $\ZZ/2$-作用均\trCompatible。

\item \emph{\trIsotopy{}不变性}。取一个由\trExact{}预\trEquivariant{}\trLagrange\trBrane{}构成的\trIsotopy，
即一个\trFamily{} $\{(L^{\#}_{s,+},P^{\#}_{s,-},f_{s,+},f_{s,-})\}$，$0\le s\le 1$。
照常，诸 $L^{\#}_{s,+}$ 决定 $HF^0(L^{\#}_{0,+},L^{\#}_{1,+})$ 的一个元素，而它们的%
\trShadow{}决定 $HF^0(L^{\#}_{0,-},L^{\#}_{1,-})$ 的一个元素。这两个元素实际上是彼此
在 $\ZZ/2$-作用 $\epsilon$ 之下的像。特别是，由此可知：若两个\trExact{}\trEquivariant{}\trBrane{}
在该类中相互\trIsotopy，则在 $H\scr{F}(M)^{\mathrm{strict}}$ 中有它们之间的一个%
\emph{不变}\trIsomorphism。\par\endgroup
\end{itemize}
